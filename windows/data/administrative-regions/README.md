# 身份证测试号地区数据

已实现：使用完整离线目录替换原来的示例地区，按省、市、区县三级选择。生成号码仅用于软件测试，地区码取最后一级正式代码。

- 全国基线：国家地名信息库截至 2025-12-31 的县级以上行政区划，来源说明见[官方发布页](https://dmfw.mca.gov.cn/XzqhVersionPublish.html)。
- 固定数据副本：[yescallop/areacodes](https://github.com/yescallop/areacodes/blob/e2c2b2e1fb4ce1fb76e879aa0b80e229adaf950c/data/2025.txt)，提交 `e2c2b2e1fb4ce1fb76e879aa0b80e229adaf950c`；数据采用 CC0 1.0，许可见本目录 LICENSE。
- 2026 增量：新疆民政厅[截至 2026-06-30 的官方表格](https://mzt.xinjiang.gov.cn/xjmzt/c112990/202607/d4e25e9ed58e4371a1798d6e623ffc3d.shtml)，第 41 页确认岑岭县 `653132`，第 67 页确认草湖市 `659013`；原图链接保存在 updates.json。

范围为大陆 31 个省级地区、341 个城市/直辖分组、2851 个末级选项。其中 2847 个为县级建制，4 个为不设县级建制的城市本级（东莞、中山、嘉峪关、儋州）。港澳台证件使用不同规则，不混入本工具的大陆居民身份证测试号。

直辖市在“市”栏使用同名市；省/自治区直辖县级建制进入“省/自治区直辖县级行政区划”分组。分组不作为生成号码的地区码；不设区县城市使用本级正式代码，不虚构区县。

执行 `node scripts/build-id-regions.js` 重建 `assets/id-regions.js`；单元测试核对快照完整性、唯一代码、上下级关联、特殊行政层级和生成号码。数据随安装包离线提供，不在使用时联网查询；不宣称包含上述基线及增量以外的后续变更。
