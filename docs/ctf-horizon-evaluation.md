## 数据与复验

历史数据含周大福 314 个日价、国际现货 302 个日价。每个基准日至少有 120 个更早的周大福报价。计算时只传入基准日前的国际日线及周大福历史，以该日周大福牌价为已知输入。统计按目标自然日取实际牌价，缺报单列。各期限的有效日期可以不同。

日线历史缺少首次发布时间与历史修订快照，这次回测以历史日价代理北京时间 10 点时的已知牌价。脚本仅读取 history 表，未补入后来在本机采集的牌价。运行中的应用还会使用此前实际采集的有效日牌价。同一历史区间已用于评估旧模型，相邻预测也共享行情。误差描述本段历史表现，未来表现需继续用发布后的真实报价核验。

在包含同一版模型的源码中运行以下命令可复验汇总。SQLite 连接为只读。

```sh
node shared/gold-core/scripts/evaluate-ctf-horizons.cjs /path/to/quotes.sqlite 2026-09-01 2026-11-20
```
