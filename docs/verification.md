## 已验证

- 金价核心与迁移共 26 项：时间调度、独立重试、断网重连、历史与币种、预测验证、贴边计算、WAL 一致性备份、已有数据不覆盖、失败清理及样例数据隔离。
- macOS：三种搜索词首位命中；金价真实窗口 20 项、3 张工具截图；本地 `x64` 与云端 `arm64` 都已运行。Universal 主程序、两个内置组件和签名完整性通过。
- Windows：真实 Windows 上运行金价 21 项检查；实际安装包再次运行完整原工具与金价回归，通过安装、启动、运行及卸载。原有主题专项 29 项也通过。详细数量、截图与性能见 [云端验证记录](../windows/docs/cloud-verification.json)。
- 两端 GUI 检查覆盖双品种报价、近一年历史、曲线键盘查值、合并与三币种换算、七日展望、命中统计、宏观/新闻/日历、明暗与置顶、贴边、最小化、关闭重开及 IPC 隔离。
- 辅助进程在本地验证了重复打开、父进程退出和 SIGTERM 清理；测试不接触正式金价数据库。

## 联网核验

北京时间 **2026-11-20 16:14**，在独立临时数据库中核验真实数据源：国际现货取得当天 Gold API 报价及 301 个历史点；周大福取得当天官方商城报价及 314 个历史点，两者均生成七日展望。

同轮取得 5 条国际事件，FOMC 与 EIA 日历可用；部分宏观或 BLS 数据未成功，状态为等待重试。已实现保留可用数据与重试；未将这些暂时不可用的来源记为通过。实时源的后续可用性取决于外部服务与网络。

## 安装包与边界

安装包来自上述 Actions，下载与 SHA-256 文件见 [v0.26.0 Release](https://github.com/innoerL/OpenAll/releases/tag/v0.26.0)。金价行情数据没有放入源码或安装包。使用、调度及迁移细节见 [金价说明](../shared/gold-desk/README.md)。

macOS 包为临时签名，未经过 Apple 公证；Windows 安装器未代码签名。正式 Developer ID 签名后的运行及公证仍待有证书环境验证。预测可信度沿用原工具的“待校准”，本次集成不构成预测准确性验证。
