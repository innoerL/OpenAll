# 0.26.1 发布验证

金价改为 OpenAll 内置工具。macOS 使用 AppKit、WebKit、JavaScriptCore 和系统 SQLite；Windows 使用宿主窗口、预加载脚本及生命周期。移除独立金价应用入口和 macOS 的附带 Electron 运行时。

## 已验证

- 共享模型与外观 26 项：调度、独立重试、断网重连、币种、预测与验证、贴边计算、WAL 一致性备份、现有数据不覆盖；32 组背景／强调色组合的语义文字和曲线对比度。
- macOS 原生后台：JavaScriptCore 与 Node 快照 3,639 个字段一致；fixture 内存隔离、原库只读 WAL 迁移、现有目标优先、币种和偏好读写通过。
- macOS 原生窗口 24 项通过，覆盖主题即时刷新、品种和曲线查值保留、桥接隔离、贴边与最小化恢复。
- Windows 端代码在本地 Electron 35.7.5 的隔离界面回归通过，实际 Windows 与安装包结果需以本轮 Actions 为准，不能以 macOS 运行结果代替。

## 联网核验
