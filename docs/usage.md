# 使用指南

## 开始使用

从 [Releases](https://github.com/innoerL/OpenAll/releases/latest) 下载对应平台版本。macOS 解压后打开 `OpenAll.app`；Windows 运行安装器。应用常驻菜单栏或系统托盘。

| 操作 | macOS 默认快捷键 | Windows 默认快捷键 |
| --- | --- | --- |
| 搜索 | `⌘Space` | `Ctrl+Space` |
| 剪贴板 | `⇧⌘V` | `Ctrl+Shift+V` |
| 复制堆栈 | `⇧⌘C` | `Ctrl+Shift+C` |
| 对选中内容操作 | `⌃⌥A` | `Ctrl+Alt+A` |

在设置中可改快捷键，或将搜索改为双击修饰键唤起。快捷键与系统冲突时，请选择其他组合。

## 搜索

输入工具名、应用名、拼音或首字母。`?` 显示功能目录，方向键选择，回车打开。输入 `=完整名称` 使用精确匹配。

文件搜索在设置中开启后，可使用类型限定词：

| 输入 | 范围 |
| --- | --- |
| `文件 报告` | 所有文件类型 |
| `文档 报告` | PDF、Word、Excel、PPT、XMind 等 |
| `图片 截图` | 图片 |
| `json 配置` | JSON 文件 |
| `.自定义后缀 名称` | 指定后缀 |

单独输入 `json` 仍打开 JSON 工具。文件范围取决于已启用目录、系统索引及访问权限。Chrome 书签与历史需要单独开启。

## 剪贴板

底部抽屉按大卡片显示复制记录，类型栏区分文本、链接、JSON、图片及文件等。支持搜索、收藏、标签、全文预览和多选；选择两张文本卡片可直接比较。

- 搜索框聚焦时，退格键删除文字；焦点在卡片上时，退格键删除焦点卡片。
- 选中卡片后按空格预览，点击窗口底部的「对内容操作」，即可用这张卡片的完整内容继续操作。
- 从工具打开剪贴板后，选择记录会回填到原来的窗口、左右侧和光标位置。
- 文本对比或 JSON 的内容查找框聚焦时，回填的是查询内容。
- 图片可进行文字识别，识别到的文字可参与搜索。

在「设置 → 剪贴板 → 卡片字号」可选大、中、小，默认使用大号。复制本地图片文件后，卡片显示缩略图和文件名，粘贴时保留原文件。可在设置中控制保留策略、暂停记录和排除应用。剪贴板历史保存在本机，请不要将历史数据作为问题附件上传。

## JSON

粘贴内容后点击“格式化”，结果直接替换当前编辑区，可继续修改。支持行号、查找、嵌套折叠、压缩、转义及键名自然排序，转换可撤销。

折叠后可编辑可见内容。全选后删除会直接清空全文（包括折叠内容），可撤销恢复；局部删除范围触及折叠块时，第一次只展开，第二次执行删除。格式错误时保留原文并提示位置。

## 文本对比

左右两侧均可编辑。新增、删除和修改行使用不同标记，修改行进一步突出变动字符、空格与缺失位置。

每侧的“自然排序”只作用于该侧，例如 `item2` 排在 `item10` 前；保留重复行、空行和末尾换行，支持撤销。大文本后台排序期间继续编辑会取消旧结果。

点击搜索按钮，或使用 `⌘F` / `Ctrl+F` 查找内容；可在差异间跳转，并切换同步滚动和忽略行尾空格。

## 金价

输入“金价”或 `gold` 回车打开。工具保留国际现货、周大福足金饰品牌价与近一年曲线；可切换美元、欧元、人民币，合并图表，查看三日展望、预测命中记录、市场因素和财经日历。贴边模式下，从搜索打开或关闭后重开，窗口至少停留 3 秒。悬停竖条可以展开窗口，再次移开鼠标即可收起。

每天北京时间 09:00 开始取价，未取到的品种会在 09:30、10:00 重试。行情卡的小字显示昨日实价和昨日存档的今日预测价。今日实价更新后，可直接看两项差额。

打开“3 日展望 → 周大福”，表格上方显示今日实采牌价。如果今天尚未取价，这里会标注最近牌价的日期。按日期比较三天的参考价和情景区间。各行共用价格刻度，彩色竖线是当天参考价，虚线是落在刻度内的今日实价。

红色上箭头表示预计涨，绿色下箭头表示预计跌，灰色横杠表示预计持平。最高方向概率低于 60% 时，灰色问号表示方向不明。点选日期可查看涨、跌、维持的概率、历史样本和估算依据。也可用上下方向键选择日期，按回车展开，按 Esc 收起。周大福的参考价按自然日分别估算，依据近期牌价涨跌和此前已收盘的国际现货日线。缺少必要数据时，点选对应日期可查看原因。方向概率未经校准。展开“实际报价验证”可查看原模型判断、实际涨跌和是否命中。旧预测按发行时的模型版本保留。[逐日回测及误差](ctf-horizon-evaluation.md)

金价背景和强调色实时跟随 OpenAll 外观设置，保留置顶开关。两种金价使用不同曲线颜色和线型，涨红、跌绿、持平中性色，配合文字标注。首次打开时安全导入原金价桌台记录；关闭窗口后继续后台取价，重新搜索即可恢复，退出 OpenAll 时停止。调度、数据路径和迁移规则见 [金价说明](../shared/gold-core/README.md)。

## 外观、权限与平台差异

在“设置 → 外观”中选择背景和强调色。当前配色带有勾选标记，点击设置分类会立即切换。按钮点击处会出现波纹，系统开启减少动态效果时使用静态反馈。

主题背景、强调色和深浅模式在设置中调整。已打开的常规工具同步更新颜色，正文和输入焦点保留；金价使用自己的明暗设置。Windows 窗口按钮位于右上角，macOS 常规工具使用原生左侧按钮，金价保留原来的浮窗标题栏。

macOS 对外部应用自动粘贴、读取选区及全局按键监听需要辅助功能授权；OpenAll 内部工具之间的文本回填不需要该授权。Windows 无法向更高权限的应用注入按键；OCR 依赖已安装的识别语言。

文件搜索覆盖已配置和已索引位置；不能保证搜索未授权或未索引的所有磁盘。翻译依赖外部网站与网络连接。安装包当前尚未公证或代码签名。

## 身份证测试号

按省、市、区县逐级选择地区；未指定部分在上级范围内随机。输入年龄后，使用今天的月日、年份减去年龄回填生日；非闰年遇到 2 月 29 日取 2 月 28 日。结果可手动修改，仅供格式验证测试。
